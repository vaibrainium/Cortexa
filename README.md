# Cortexa

Cortexa is an AI-powered research assistant designed to brainstorm neuroscience research ideas and discuss potential experiments using a Large Language Model (LLM) agent.

## Features
- **AI-Driven Brainstorming**: Generate novel neuroscience research ideas.
- **Experiment Design**: Discuss and refine potential experimental setups.
- **Paper Recommendations**: Get relevant literature suggestions based on key topics.
- **Interactive Discussions**: Engage in dynamic conversations with the LLM to refine hypotheses.

## Installation

Clone the repository:
```sh
git clone https://github.com/vaibrainium/cortexa.git
cd cortexa
```

Install dependencies:
```sh
pip install -r requirements.txt
```

## Usage
Run the Cortexa assistant:
```sh
python cortexa.py
```
Start brainstorming neuroscience research ideas interactively!
